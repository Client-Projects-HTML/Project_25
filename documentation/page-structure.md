# Page Structure

| Page | File | Purpose |
|---|---|---|
| Home | `pages/index.html` | Hero, about preview, why-choose-us, services preview, testimonials preview, CTA, FAQ preview |
| About | `pages/about.html` | Company story, mission/vision, designer team, awards, work process |
| Services | `pages/services.html` | Grid of all 8 services with links to detail pages |
| Painting | `pages/painting.html` | Room-by-room painting services and finish types |
| Wallpaper | `pages/wallpaper.html` | Wallpaper categories |
| Furniture | `pages/furniture.html` | Furniture styling categories |
| Curtains | `pages/curtains.html` | Curtain and blind categories |
| Lighting | `pages/lighting.html` | Lighting categories |
| Gallery | `pages/gallery.html` | Filterable photo grid + before/after, with skeleton loading state |
| Projects | `pages/projects.html` | Case studies of completed projects |
| Pricing | `pages/pricing.html` | Basic/Standard/Premium packages + payment placeholder |
| Testimonials | `pages/testimonials.html` | Full list of client reviews |
| FAQ | `pages/faq.html` | Accordion of common questions |
| Consultation | `pages/consultation.html` | Booking form + service cost calculator |
| Contact | `pages/contact.html` | Address, phone, email, map, contact form |
| Enquiry | `pages/enquiry.html` | Enquiry form with file upload for reference photos |
| Privacy Policy | `pages/privacy-policy.html` | Placeholder policy text |
| Terms | `pages/terms.html` | Placeholder terms text |
| 404 | `pages/404.html` | Custom not-found page |
| Coming Soon | `pages/coming-soon.html` | Pre-launch placeholder with countdown + email signup |

## Shared Components
Every page includes the same header (logo, nav, dark/light toggle, RTL toggle, mobile hamburger) and footer (newsletter signup, quick links, services links, contact info, social icons), generated from one template so they stay consistent — see `documentation/customization-guide.md` if you're editing the source generator scripts rather than the HTML directly.
