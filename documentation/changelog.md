# Changelog

## v1.0.0 — 2026-07-27
- Initial release: full 19-page static site built to the Interior Painting & Home Decor brief and the HTML Template Development Guide.
- Added dark/light mode toggle with OS-preference detection.
- Added RTL layout support and toggle.
- Added accessibility baseline: skip link, visible focus states, 44px touch targets, `prefers-reduced-motion` support, ARIA labels/roles on nav, FAQ, and gallery filters.
- Added skeleton loading state on the Gallery page.
- Added SEO basics: per-page meta descriptions, unique titles, JSON-LD business schema on the homepage, `sitemap.xml`, `robots.txt`.
- Added placeholder-ready integrations: Formspree-style contact form action, newsletter signup, Google Maps embed, date-based booking field, disabled Stripe/PayPal buttons.
- Restructured project so all HTML lives under `/pages/`, assets under `/assets/`, with a new `/documentation/` folder.
