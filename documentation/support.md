# Support

This is a self-contained static template — there's no backend to maintain.

**Common questions:**
- *Forms aren't sending anywhere* — that's expected out of the box. See `customization-guide.md` under "Forms & Integrations" to connect Formspree, Netlify Forms, or your own backend.
- *Dark mode / RTL toggle resets on refresh* — by design in this delivery (no `localStorage` used). See the customization guide to persist the choice.
- *Images look like stock photos* — they are placeholders from Unsplash. Swap them for your own in `assets/images/`.

If you're extending this template and want a second pass (new pages, a booking backend, real payment integration, translations for RTL languages, etc.), just ask in the same chat where this was built.
