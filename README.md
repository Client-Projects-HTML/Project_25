# Bloom Interiors — Interior Painting & Home Decor Website

A 19-page static website template (HTML5, CSS3, vanilla JavaScript — no framework, no build step) for a residential interior painting and home decor business.

## Quick Start
See `documentation/installation-guide.md`.

## What's Included
- Full page set: Home, About, Services (+4 sub-service pages: Painting, Wallpaper, Furniture, Curtains, Lighting), Gallery, Projects, Pricing, Testimonials, FAQ, Consultation, Contact, Enquiry, Privacy Policy, Terms, 404, Coming Soon
- Dark/light mode toggle with OS-preference detection
- RTL layout support and toggle
- Accessible by default: skip link, visible focus states, 44px touch targets, reduced-motion support
- Skeleton loading state on the Gallery page
- Service cost calculator on the Consultation page
- File upload on the Enquiry page
- Per-field form validation with inline error messages
- SEO basics: meta descriptions, JSON-LD schema, sitemap.xml, robots.txt
- Placeholder-ready integrations: contact form (Formspree-style), newsletter signup, Google Maps embed, date-based booking, disabled Stripe/PayPal buttons
